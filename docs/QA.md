# Проверка версии 0.1 — 27 октября 2026

Проверено на macOS Apple Silicon (arm64), Electron 45.0.0. Использовались только вымышленные данные.

- Локальная сборка `.app`, ad hoc подпись, запуск и повторный запуск — успешно.
- Демо: 48 учеников в четырёх классах, два обследования; неполные ответы учитываются отдельно — успешно.
- Нативный интерфейс: открытие и редактирование анкеты, сохранение заметки; запись подтверждена чтением SQLite — успешно.
- Матрица социометрии и сравнение двух периодов отображаются; сохранены скриншоты `matrix.png` и `history.png`.
- Создание отдельной пустой базы, добавление ученика в новый класс и обследования через интерфейс — успешно. Демо затем повторно открыто через системный диалог.
- Экспорт PDF через системный диалог: две страницы A4, русский текст и таблицы проверены визуально после рендеринга. Заголовок метаданных PDF корректный.
- Экспорт CSV: UTF-8 BOM, 13 строк (заголовок + 12 учеников), 19 колонок, сохранённая заметка присутствует.
- `npm test`: 7 тестов прошли. Проверяются расчёты с пропусками, изоляция классов/дат, взаимные пары, валидация выборов и шкал, экранирование CSV, реальное сохранение и повторное открытие SQLite, уникальность ответов и внешние ключи после экспорта базы.
- GitHub Actions: проверка на Ubuntu / Node 24 прошла успешно для первого коммита.
- Официальный ZIP Electron проверен по SHA-256 из пакета Electron перед сборкой.

Windows x64: команда упаковки предусмотрена, нативный запуск не проверялся. Intel Mac: отдельная сборка не подготовлена. Нет Developer ID/нотариализации Apple.

Приложение и правила обработки предварительные. На реальных детских анкетах и в работе школьного психолога не проверено. Полные методические ключи и форму заключения должен подтвердить заказчик/специалист. Проверка не является валидацией психологических методик.
