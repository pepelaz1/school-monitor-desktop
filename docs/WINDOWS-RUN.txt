Школьный мониторинг 0.2.0 — Windows 11 x64

1. Полностью распакуйте ZIP в обычную папку, например Documents\SchoolMonitor.
2. Откройте эту папку и запустите SchoolMonitor.exe.
3. Не переносите EXE отдельно: рядом нужны DLL, папки resources и locales.

Node.js, Python, отдельная установка SQLite и интернет для работы не нужны.
При первом запуске открываются вымышленные демоданные. Новую рабочую базу можно
создать в разделе «База и правила». Данные от версии 0.1 совместимы.

Программа не подписана сертификатом Authenticode. Нативная работа на Windows
в этой среде не проверялась; сборка и содержимое архива проверены на macOS.

Исходный код: https://github.com/pepelaz1/school-monitor-desktop
Правила обработки и ограничения: README.md в репозитории.
